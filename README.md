# Cat of Duty
Copyright © 2026 Team MGS

## 概要
Cat of Dutyは、第99回五月祭にて東大VRサークル「UT-virtual」が展示したVRゲームです。

体験者は強力な反動を味わえるマシンガン型コントローラーを手に取り、猫が操縦する宇宙船に乗ってエイリアンを撃破します。敵要塞に突入して、奪われた猫村の宝を取り返します。

## 操作方法
- T または マウス左ボタン：発射
- マウス移動：視点回転（デスクトップモードのみ）
- H：宇宙船の移動モード切り替え（自動・手動）
- R: 次のフェーズに進む
- S: 無敵になるシールド発動
- スペース：リトライ
- Escape：メニューに戻る

## VRモードについて
- 本作品のVRモードは、展示会にて用いられる銃型コントローラを想定して開発されたものです。
- Meta Quest 3・Meta Quest Link・SteamVRの組み合わせで動作確認済みです。
